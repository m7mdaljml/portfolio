# Mohammad Aljamal - Portfolio

A personal portfolio website for a Front-End Engineer, built with React, TypeScript, and Vite.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- wouter (routing)
- TanStack React Query
- Firebase / Firestore (content management, knowledge base, visitor tracking)
- shadcn/ui components (Radix UI primitives)
- EmailJS (contact form)

## Features

- Bilingual portfolio (English / Arabic with full RTL support)
- Light / dark theme
- AI chat assistant powered by Groq
- Live GitHub repositories showcase
- Content management via a password-protected admin dashboard
- Anonymous visitor tracking stored in Firestore, viewable in the admin dashboard
- Custom 404 page
